# S3.D.01 - Développement d'une application
Cette application a pour but de gérer les données des expositions d'un musée. Pour parvenir à cet objectif, cette application donne accès à de nombreuses fonctionnalités. Les données peuvent être importées depuis le site web du musée ou bien directement depuis un autre poste de travail du musée. Les échanges entre les postes de travail du musée se font de manière cryptée. Les données collectées pourront ensuite être utilisées pour faire des statistiques et générer des rapports. Sinon, l'application permet simplement de consulter des données ou d'effectuer des calculs sur ces données. Le résultat de toutes ces fonctionnalités est accessible depuis l'application.
